How it works

From browser actions to an illustrated procedure

  1. Choose a short, repeatable browser task.

    Pick a supported workflow with a clear start and finish, such as entering a request or preparing a weekly report. Avoid real confidential information during examples.

  2. Start the TeachAtlas recorder.

    Install the extension in a supported browser, allow access where needed, and decide whether to capture screenshots.

  3. Perform the task normally.

    Follow the steps in the browser. The recorder captures supported actions; browser security restrictions may exclude certain pages, fields or frames.

  4. Review and correct the generated steps.

    Shorten repetitive instructions, add missing context, remove sensitive details and verify any screenshots.

  5. Export and test.

    Save an available export format for your edition, ask someone else to follow the instructions and revise unclear steps. Supported Pro versions can also combine guides into manuals and publish guides or manuals using optional public links. Anyone with a link can view and copy the content. Revocation cannot remove previously saved copies.

Practical example

Example guide: Save a report as a PDF

The following is an illustrative browser workflow, not an image of a live TeachAtlas recording. Exact steps vary by website.

Step 01

Open the report

Sign in to the reporting tool and choose the report you need. Check its date range before exporting.

Step 02

Review the content

Confirm that filters and totals match the intended reporting period. Do not include restricted information.

Step 03

Export and verify

Choose the website’s download/export action. Open the resulting PDF and verify it is legible and complete.

Illustrative example: it describes exporting a report within a website, not a promised TeachAtlas feature on every site.

Frequently asked questions

Can a browser extension record everything on my computer?

No. TeachAtlas is intended for supported browser workflows; it does not record native desktop applications. Browser security restrictions and website permissions also apply.

Do I need screenshots?

No. Text-only instructions can be appropriate for simple workflows. Use screenshots when a visual cue helps, and inspect every image before exporting or sharing. Screenshots are not automatically redacted; remove or cover sensitive information, and use only content you are authorized to record and distribute.

Are the instructions automatically perfect?

No. Review every guide for clarity, privacy, current interface labels and missing steps.
